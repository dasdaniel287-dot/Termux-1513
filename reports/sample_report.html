HIGH

Strict-Transport-Security Missing

ID: HDR-HSTS-MISSING · Confidence: Confirmed

Component: HTTP Response Headers

Evidence: Strict-Transport-Security header not present in HTTPS response.

Technical Analysis: HTTP Strict Transport Security (HSTS) instructs compliant browsers that the domain must only be contacted over HTTPS for a specified duration.

Potential Impact: Vulnerable to Man-in-the-Middle (MitM) SSL stripping and insecure HTTP downgrades when users first visit via bookmark or typed domain.

RECOMMENDED REMEDIATION:
Add 'Strict-Transport-Security: max-age=31536000; includeSubDomains; preload' in web server config.
# Verification step:
curl -sI https://example.org | grep -i strict-transport-security
HIGH

Content-Security-Policy Header Missing

ID: HDR-CSP-MISSING · Confidence: Confirmed

Component: HTTP Response Headers

Evidence: Content-Security-Policy header not returned in response.

Technical Analysis: Content Security Policy (CSP) is a critical defensive HTTP response header that helps prevent and mitigate Cross-Site Scripting (XSS), data injection, and malicious clickjacking.

Potential Impact: Higher blast radius if an XSS flaw exists on the application layer.

RECOMMENDED REMEDIATION:
Define a strict CSP beginning with: default-src 'self'; script-src 'self'; object-src 'none'; base-uri 'self'; frame-ancestors 'none';
# Verification step:
curl -sI https://example.org | grep -i content-security-policy
MEDIUM

X-Content-Type-Options Header Missing

ID: HDR-XCTO-MISSING · Confidence: Confirmed

Component: HTTP Response Headers

Evidence: X-Content-Type-Options header was not returned.

Technical Analysis: X-Content-Type-Options stops browsers from MIME-sniffing a response away from the declared content-type.

Potential Impact: Browsers may interpret non-executable MIME types as executable JavaScript or HTML, leading to Drive-by downloads or XSS.

RECOMMENDED REMEDIATION:
Configure header: X-Content-Type-Options: nosniff
# Verification step:
curl -sI https://example.org | grep -i x-content-type-options
MEDIUM

Clickjacking Protection Missing (X-Frame-Options)

ID: HDR-XFO-MISSING · Confidence: Confirmed

Component: HTTP Response Headers

Evidence: Neither X-Frame-Options nor CSP frame-ancestors detected.

Technical Analysis: The X-Frame-Options header indicates whether a browser should be allowed to render a page inside a frame or iframe.

Potential Impact: UI redressing / Clickjacking attacks could trick authenticated users into unauthorized clicks.

RECOMMENDED REMEDIATION:
Add 'X-Frame-Options: DENY' or 'X-Frame-Options: SAMEORIGIN', and include CSP 'frame-ancestors'.
