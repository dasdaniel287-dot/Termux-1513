# ওয়েবশিল্ড এআই — ব্যবহার নির্দেশিকা ও ডকুমেন্টেশন (বাংলা)

**ওয়েবশিল্ড এআই (WebShield AI)** হলো একটি আধুনিক, নির্ভরযোগ্য এবং নিরাপদ ওয়েবসাইট সিকিউরিটি অ্যাসেসমেন্ট টুল, যা অ্যান্ড্রয়েড ডিভাইসের **Termux** টার্মিনালে চালানোর জন্য বিশেষভাবে তৈরি করা হয়েছে। কোনো প্রকার রুট অ্যাক্সেস (Root Permission) ছাড়াই এটি সাধারণ ওয়েবসাইট মালিক ও অনুমোদিত সিকিউরিটি টেস্টারের জন্য ওয়েবসাইটের নিরাপত্তা কনফিগারেশন নিরীক্ষা করে এবং পূর্ণাঙ্গ রিপোর্ট তৈরি করে।

---

## ১. টার্মাক্সে (Termux) সহজ ইনস্টলেশন

আপনার অ্যান্ড্রয়েড ফোনে Termux অ্যাপ ওপেন করে নিচের কমান্ডগুলো রান করুন:

```bash
# প্যাকেজ আপডেট ও আপগ্রেড করুন
pkg update -y && pkg upgrade -y

# পাইথন, গিট ও ওপেন-এসএসএল ইনস্টল করুন
pkg install -y python git openssl

# গিটহাব থেকে ক্লোন করুন
git clone https://github.com/webshield-ai/webshield-ai.git
cd webshield-ai

# ইনস্টলার স্ক্রিপ্ট এক্সিকিউট করুন
chmod +x install.sh run.sh
./install.sh
```

*(কোনো রুট অ্যাক্সেসের প্রয়োজন নেই!)*

## ২. কমান্ডের ব্যবহার নির্দেশিকা

### সিস্টেম কনফিগারেশন চেক
```bash
python3 main.py --check-config
```

### অনুমোদিত ওয়েবসাইটে সিকিউরিটি স্ক্যান চালানো
```bash
python3 main.py --target https://your-authorized-domain.com --authorized
```
*(লক্ষ্য করুন: `--authorized` ফ্ল্যাগটি নিশ্চিত করে যে আপনি সাইটটির মালিক অথবা স্ক্যান করার স্পষ্ট অনুমতি আপনার রয়েছে। এটি অননুমোদিত অ্যাক্সেস প্রতিরোধ করে।)*

### ফলাফল JSON ফরম্যাটে পেতে
```bash
python3 main.py --target https://your-authorized-domain.com --authorized --json
```

### পূর্বের স্ক্যান হিস্ট্রি দেখতে
```bash
python3 main.py --history
```

### ইন্টারঅ্যাক্টিভ মেনু
টার্মিনালে সরাসরি নিচের কমান্ডটি রান করলেই বাংলা ও ইংরেজি মেনু পেয়ে যাবেন:
```bash
./run.sh
```

## ৩. প্রধান সিকিউরিটি চেকসমূহ

| বিভাগ | নিরীক্ষিত বিষয়সমূহ | নিরাপত্তার গুরুত্ব |
| :--- | :--- | :--- |
| **সেফটি ও অ্যান্টি-SSRF** | ইউআরএল যাচাই, অনুমোদন নিশ্চিতকরণ, প্রাইভেট/লুপব্যাক আইপি ব্লক | লোকালহোস্ট (127.0.0.1) বা ইন্টারনাল ক্লাউড মেটাডেটা আক্রমণ প্রতিরোধ করে। |
| **টিএলএস / এসএসএল সার্টিফিকেট** | সার্টিফিকেটের মেয়াদ, মেয়াদ শেষ হতে বাকি দিন, সিএ ট্রাস্ট, টিএলএস প্রোটোকল (TLS 1.2/1.3) | ব্রাউজারে লাল ওয়ার্নিং আসা ঠেকায় এবং ট্রাফিক এনক্রিপশন নিশ্চিত করে। |
| **এইচটিটিপি সিকিউরিটি হেডার** | HSTS, CSP, X-Content-Type-Options, X-Frame-Options, Referrer-Policy, Permissions-Policy | XSS, ক্লিকজ্যাকিং এবং ডেটা লিক থেকে ব্যবহারকারীদের রক্ষা করে। |
| **ডিএনএস রেকর্ড নিরীক্ষা** | A, AAAA, MX, NS, TXT, SPF (`v=spf1`), DMARC (`v=DMARC1`) | ডোমেইনের বৈশ্বিক প্রাপ্যতা এবং ইমেইল স্পুফিং (Phishing) প্রতিরোধ করে। |
| **সার্ভার কনফিগারেশন** | এইচটিটিপি থেকে এইচটিটিপিএস অটোমেটিক রিডাইরেক্ট, সার্ভার ভার্সন ডিসক্লোজার, `security.txt` ও `robots.txt` | এনক্রিপ্টেড চ্যানেলে ভিজিটরকে পাঠায় এবং স্পর্শকাতর পাথ লিক হওয়া থামায়। |

## ৪. স্কোরিং সিস্টেম (০ থেকে ১০০)

ওয়েবশিল্ড এআই কোনো মনগড়া স্কোর দেয় না; বরং প্রতিটি ঝুঁকি এবং আত্মবিশ্বাসের ওপর ভিত্তি করে স্কোর নির্ণয় করে:
- **বেস স্কোর:** ১০০ পয়েন্ট
- **ক্রিটিক্যাল ঝুঁকি (-২৫ পয়েন্ট):** মেয়াদোত্তীর্ণ এসএসএল, অবিশ্বস্ত সার্টিফিকেট চেইন।
- **উচ্চ ঝুঁকি (-১৫ পয়েন্ট):** এইচটিটিপিএস ছাড়া সাইট চলা, HSTS অনুপস্থিত থাকা, CSP না থাকা।
- **মাঝারি ঝুঁকি (-৮ পয়েন্ট):** ক্লিকজ্যাকিং প্রতিরোধে X-Frame-Options না থাকা, X-Content-Type-Options অনুপস্থিত।
- **স্বল্প ঝুঁকি (-৩ পয়েন্ট):** সার্ভার ভার্সন ডিসক্লোজ করা, Referrer-Policy না থাকা।

### গ্রেড তালিকা:
- **A+ (৯৫-১০০)**: অত্যন্ত সুরক্ষিত ও সুদৃঢ় কনফিগারেশন
- **A (৯০-৯৪)**: শক্তিশালী আধুনিক নিরাপত্তা
- **B (৮০-৮৯)**: সন্তোষজনক, তবে কিছু হেডার যুক্ত করা প্রয়োজন
- **C (৭০-৭৯)**: মাঝারি ঝুঁকি বিদ্যমান, অবিলম্বে সমাধান করা দরকার
- **D (৬০-৬৯)**: গুরুতর কনফিগারেশন সমস্যা
- **F (<৬০)**: অনিরাপদ ও ঝুঁকিপূর্ণ অবস্থা

## ৫. রিপোর্ট ডাউনলোড ও সংরক্ষণ

প্রতিটি স্ক্যান সম্পন্ন হলে `reports/` ফোল্ডারে স্বয়ংক্রিয়ভাবে ৩টি ফাইল সংরক্ষিত হয়:
1. **HTML রিপোর্ট (`.html`)**: ব্রাউজারে দেখার মতো আধুনিক ও সুন্দর ভিজ্যুয়াল রিপোর্ট।
2. **JSON রিপোর্ট (`.json`)**: যেকোনো স্ক্রিপ্ট বা পাইপলাইনে প্রসেস করার জন্য ডেটা ফাইল।
3. **টেক্সট রিপোর্ট (`.txt`)**: টার্মিনালে `cat` বা `nano` দিয়ে সহজে পড়ার উপযোগী ফরম্যাট।

## ৬. অ্যান্ড্রয়েড স্টোরেজে রিপোর্ট দেখতে

টার্মাক্স থেকে সরাসরি ফোনের ফাইল ম্যানেজারে রিপোর্ট পাঠাতে নিচের কমান্ডটি দিন:
```bash
termux-setup-storage
mkdir -p /sdcard/WebShield
cp reports/*.html /sdcard/WebShield/
```
এখন আপনার ফোনের যেকোনো ব্রাউজার দিয়ে `/sdcard/WebShield` ফোল্ডারের ফাইল ওপেন করতে পারবেন।
